## 2. Artwork

Every file under `public/assets/` is original, hand-authored vector art (SVG and JSON
palette data). It was produced by code in `scripts/art/`, so the art can be regenerated
with `npm run art` and validated with `npm run art:check`. The art was created with AI
assistance (Claude). It contains no third-party images and no output from an AI image
generator. It is released under the same MIT licence as the game.

| Asset group | Files | Notes |
|---|---|---|
| Board, snakes and bridges | atlas sheets (`iso/blocks`, `iso/shared`, `iso/props`, `iso/frame`, `iso/snakes-<level>`, `iso/bridges-<level>`) and the Hanuman figurines in `iso/` | Built by the isometric build scripts in `scripts/art/iso/` (`npm run art:all`) |
| Icons | `icons/favicon.svg` | Browser favicon (generated by `scripts/art/tokens.mjs`) |
| Tokens | `tokens/rama.svg`, `tokens/sita.svg`, `tokens/lakshmana.svg`, `tokens/hanuman.svg` | Four player tokens (`scripts/art/tokens.mjs`) |

The in-game hero figures and faces are drawn procedurally in `src/characters/`
(`Character.ts`, `faces.ts`), not from SVG files.

Design rules for the art are in `docs/design/T02-style-guide.md` and
`docs/design/T03-board-art.md`. The hero personalities and reactions are in
`docs/design/T01-heroes.md` and `docs/design/T05-emotion-timing.md`.

## 5. Audio

All sounds are synthesized at runtime with the Web Audio API (`src/game/audio.ts`); no audio files are included.

## 6. Story

The story is based on the Ramayana, the ancient Sanskrit epic attributed to Valmiki. The
Ramayana is in the public domain. The game text, including all dialogue and UI strings,
is original.
